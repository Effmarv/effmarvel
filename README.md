# effmarvel.com

Personal portfolio for Marvelous Effiong. Plain HTML and CSS, hosted free on Cloudflare.

- `public/` is the website. The homepage is `public/index.html`.
- Case study pages are generated by `python3 src/build.py` (edit the text there, then run it).
- `wrangler.jsonc` tells Cloudflare to serve the `public/` folder. No build step is needed.
